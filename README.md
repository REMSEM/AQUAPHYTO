# AQUAPHYTO

Hyperspectral detection and classification of phytoplankton groups from in-situ radiometer data (PANTHYR, Hypstar, WISP) and simulated CHIME spectra.

This repository provides a Python processing pipeline for the automated detection of *Phaeocystis globosa*, diatoms, and cyanobacteria in Belgian coastal waters using in-situ hyperspectral water reflectance (ρ_w) measured by the PANTHYR autonomous radiometer network. A dedicated module (`phytospec.cyano`) detects cyanobacteria in lakes and brackish waters from the phycocyanin absorption feature near 620 nm.

The pipeline converts raw PANTHYR CSV files into a quality-controlled, ML-ready dataset containing per-day spectral indices and classification labels, designed to feed downstream machine learning models.

This pipeline has been developed with the [OBAMA-NEXT](https://obama-next.eu/) project (WP2) and optimized within the [ESA-AQUATIME](https://sup.apex.esa.int/en/aquatime) project, including adaptation to detect Cyanobacteria (WP3).

---

## Algorithms implemented

| Index / method | Species target | Reference |
|---|---|---|
| **MALH** — Modified Astoreca Line Height | *P. globosa* | Lavigne et al. (2022) |
| **Lubac D² classifier** — second derivative of ρ_wN | *P. globosa* | Lubac et al. (2008) |
| **CRAT** — NIR-red chlorophyll-a | bloom biomass | Ruddick et al. (2001) |
| **D²(620) rule** — second derivative of ρ_w at the phycocyanin trough; D²(620) > 0 → Cy+ | cyanobacteria | AQUATIME WP3 |
| **PC_T** — phycocyanin trough depth (597.5 / 622.5 / 647.5 nm) | cyanobacteria | experimental, not used for detection |

Water absorption uses the Buiteveld et al. (1994) look-up table with temperature correction (default T = 10 °C, Belgian coastal water).

## Quick start

### Step 1 — Build the datacube from raw files

Open `notebooks/01_build_datacube.ipynb` and set `STATION` and `YEAR`:

```python
STATION = "RT1"
YEAR    = 2025
```

This reads all `*QA_data.csv` files from `data/raw/RT1_2025/`, applies quality control (sun-glint filter, NaN filter), and saves a compressed datacube to:

```
data/processed/datacube_RT1_2025.npz
```

### Step 2 — Compute spectral indices and build the ML dataset

Open `notebooks/02_make_dataset.ipynb`. Running `make_dataset()` computes CHL, MALH, D²ρ_w, and the Lubac *P. globosa* label for each spectrum, selects one spectrum per day (closest to solar noon), and saves the result as:

```
data/processed/REFERENCE_DATASET_4_WP2_RT1_2025.csv
```

### Step 3 — Exploratory analysis

`notebooks/03_analysis_visualization.ipynb` provides mean spectral signatures, interquartile ranges, and MALH vs Chl-a scatter plots by species class.

### Step 4 — LightGBM MALH retrieval (Case Study 1)

`notebooks/06_LGBM_MALH_CS1.ipynb` trains a LightGBM regressor to predict MALH under CHIME satellite revisit gaps using ancillary data and the last known MALH value. Requires the prepared datasets in `data/raw/DATA_FOR_ML/`.

### Step 5 — Cyanobacteria detection (multi-site)

Open `notebooks/AQUAPHYTO-DETECT/05_cyano_normalization_sensitivity_v2.ipynb` and select the site in §1:

```python
DATASET = "vortsjarv_hypstar"   # or "sodra_wisp", "gorvaln_chime_sim", "dalaro_chime_sim_daily"
```

The notebook applies quality control, computes D²(620) on a common spectral scale (10 nm effective resolution for measured spectra), validates the Cy+/Cy− classes against in-situ taxonomy (cyanobacteria-dominated if ≥ 30 % of biomass) and tests the sensitivity to normalisation and spectral scale. Södra results are preliminary.

## Configuration

All paths and algorithm constants are centralised in `phytospec/config.py`. Edit only that file when adapting the pipeline to a new station or year.

Key parameters:

| Parameter | Default | Description |
|---|---|---|
| `D2_NORM_WL` | `None` (→ 442.5 nm) | Normalisation wavelength for D² |
| `D2_DELTA` | 2.5 nm | Wavelength step for second derivative |
| `BUITEVELD_T` | 10.0 °C | Water temperature for absorption correction |
| `QC_SZA_MAX` | 75° | Maximum solar zenith angle |
| `QC_LDEX_MAX` | 0.05 sr⁻¹ | Maximum Ld/Ed ratio at 750 nm |
| `CY_D2_WL` | 620.0 nm | Cyanobacteria rule: D²(620) > 0 → Cy+ |
| `CY_SMOOTH_FWHM` | 10.0 nm | Effective resolution for measured spectra before D² |
| `CY_DESIGN_STEP` | 2.5 nm | Regular grid for fine-resolution sensors |
| `CY_DOM_FRAC` | 0.30 | In-situ threshold for cyanobacteria dominance |

## Data format

### Input — raw PANTHYR CSV (`*QA_data.csv`)

| Column | Description |
|---|---|
| `wavelength` | Wavelength [nm] |
| `rhow_nosc` | Water reflectance, sky-glint corrected [sr⁻¹] |
| `lu` | Upwelling radiance [W m⁻² nm⁻¹ sr⁻¹] |
| `ed` | Downwelling irradiance [W m⁻² nm⁻¹] |
| `solar_zenith_angle` | Solar zenith angle [°] |

### Output — ML-ready dataset CSV

Columns: `date`, `CHL`, `MALH`, `P_LUB`, `rhow_355.0` … `rhow_945.0`, `D2rhow_355.0` … `D2rhow_945.0`
